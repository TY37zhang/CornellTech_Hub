# Cornell Tech Course Scraper

This Python scraper extracts course data from Cornell's course roster for the New York Tech Campus (NYT) and saves it locally as JSON and CSV files. A separate script handles database updates.

## Folder Structure

```
scraper/
├── run_scraper.sh           # Main execution script
├── README.md               # This documentation
├── cornell_courses.json    # Generated course data (JSON)
├── cornell_courses.csv     # Generated course data (CSV)
├── venv/                   # Virtual environment (auto-generated)
└── scripts/                # Python scripts and dependencies
    ├── cornell_courses_scraper_v2.py  # Main scraper script
    ├── update_database.py              # Database updater
    ├── test_connection.py              # Database connection tester
    ├── test_scraper.py                 # Scraper functionality tester
    └── requirements.txt                # Python dependencies
```

## Features

- ✅ Scrapes Cornell Tech course listings for Fall 2025
- ✅ Extracts course codes, names, descriptions, credits, and instructors
- ✅ Saves data as both JSON and CSV files locally
- ✅ Separate database updater with preview functionality
- ✅ Handles duplicate detection and updates
- ✅ Comprehensive logging and error handling
- ✅ No course schedules (user-customized)

## Two-Step Process

### Step 1: Scrape Data

The main scraper downloads course data and saves it locally (no database connection needed).

### Step 2: Update Database

A separate script reads the local files and updates your database with preview functionality.

## Prerequisites

- Python 3.7+
- PostgreSQL database (your existing CornellTech_Hub database) - only for Step 2
- No special permissions needed for scraping

## Installation & Setup

1. **Navigate to the scraper directory:**

    ```bash
    cd scraper
    ```

2. **Run the scraper (Step 1):**

    ```bash
    chmod +x run_scraper.sh
    ./run_scraper.sh
    ```

    Or manually:

    ```bash
    python3 -m venv venv
    source venv/bin/activate
    pip install -r scripts/requirements.txt
    python3 scripts/cornell_courses_scraper_v2.py
    ```

3. **Preview database changes (Step 2):**

    ```bash
    export DATABASE_URL="your_postgresql_connection_string"
    python3 scripts/update_database.py cornell_courses.json --preview
    ```

4. **Update database (Step 2):**
    ```bash
    python3 scripts/update_database.py cornell_courses.json
    ```

## Database Schema

The database updater works with your existing Prisma schema and inserts data into the `courses` table:

### Course Data Structure

Each course record includes:

- `code`: Course code (e.g., "CS 5112")
- `name`: Course title
- `description`: Course description (when available)
- `credits`: Number of credits
- `department`: Department code (e.g., "CS")
- `professor_id`: Instructor name
- `semester`: "Fall"
- `year`: 2025
- `full_code`: Extended course code
- `scraped_at`: Timestamp of when data was scraped

## Database Updater Usage

### Preview Changes (Recommended First)

```bash
python3 scripts/update_database.py cornell_courses.json --preview
```

### Update Database

```bash
# Update existing courses and insert new ones (default)
python3 scripts/update_database.py cornell_courses.json

# Only insert new courses, skip existing ones
python3 scripts/update_database.py cornell_courses.json --no-update

# Use CSV file instead of JSON
python3 scripts/update_database.py cornell_courses.csv
```

### Command Line Options

- `--preview`: Show what changes would be made without updating
- `--no-update`: Skip updating existing courses
- `--database-url`: Specify database URL (or use DATABASE_URL env var)

## Troubleshooting

### Common Issues

1. **Scraping Failed:**

    - Check internet connectivity
    - Cornell's website structure may have changed
    - Check `cornell_page.html` for actual page content
    - The scraper includes fallback sample data

2. **Database Update Failed:**

    - Verify your DATABASE_URL is correct
    - Check database server is running
    - Ensure database write permissions
    - Use `--preview` to test connection first

3. **File Not Found:**
    - Make sure you ran the scraper first
    - Check that JSON/CSV files were generated
    - Run from the correct directory

### Logs

Both scripts provide detailed logging:

- INFO: General progress updates
- ERROR: Issues with specific courses or database operations
- WARNING: Non-critical issues

## Customization

### Adding More Courses

To add courses not automatically detected, modify the `sample_courses` list in `scripts/cornell_courses_scraper_v2.py`.

### Changing Semester/Year

Update the `semester` and `year` values in the `parse_course_from_html` method.

### Different Campus

Modify the `search_url` to target different campuses by changing the `campus` parameter.

## API Integration

After running the database updater, the courses will be available through your existing API endpoints:

- `GET /api/courses` - List all courses
- `GET /api/courses/search` - Search courses
- `GET /api/courses/[id]` - Get specific course details

## Scheduling

For regular updates, consider setting up a cron job:

```bash
# Run daily at 6 AM
0 6 * * * cd /path/to/scraper && ./run_scraper.sh && python3 scripts/update_database.py cornell_courses.json
```

## Advantages of Two-Step Process

1. **Safety**: Preview changes before applying them
2. **Reliability**: Scraping doesn't depend on database connectivity
3. **Flexibility**: Can modify scraped data before database update
4. **Debugging**: Easy to inspect scraped data in JSON/CSV format
5. **Reusability**: Can update database multiple times with same data
